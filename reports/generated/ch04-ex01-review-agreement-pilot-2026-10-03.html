AI EVALS KNOWLEDGE BASE · CHAPTER 4 · EXERCISE 1

Review-Agreement Pilot

A small manual review shows why a clear rubric still needs the right cases and more than one reviewer.

3 OCTOBER 2026 · 10 FIXED RECIPE BOT TRACES · WORKING ARTIFACT: RECIPE-BOT-REVIEW-AGREEMENT

1 · The question

Boss, can one reviewer apply a simple requested-ingredient rule consistently enough to justify an automated evaluator?

The rule

Mark Pass when each specifically named ingredient in the user request appears in the recipe’s ingredient list or instructions. Mark Fail when one is missing.

Salmon fillet counts as salmon; lemon juice counts as lemon.

The scope

Recipe taste, dietary claims, cooking time, and pantry claims were deliberately excluded. The review tested only ingredient inclusion.

One rubric per criterion keeps the evidence interpretable.

In plain terms: This is like checking whether a market-shopping list was fulfilled. Before judging price or quality, first ask whether every requested item made it into the bag.

2 · What the pilot did

The owner wrote the rubric, selected ten fixed traces, and completed one independent label pass. Each row records a label and a short reason.

ItemResultWhat it means
Shared trace set10 tracesFixed Recipe Bot IDs make the review reproducible.
Reviewer A10 Pass · 0 FailEvery selected recipe contained the requested ingredients.

Cohen’s KappaNot reportedOne reviewer and one label class cannot provide meaningful chance-adjusted agreement.
What worked: The requested-ingredient rubric was easy for the owner to apply without specialist dietary or medical knowledge.

3 · The important limitation

One reviewer is not agreement

A personal label pass can check that a rubric is usable. It cannot show that another person would read the rule in the same way.

Easy cases hide ambiguity

Ten Pass cases may create perfect-looking agreement without testing the boundary between Pass and Fail.

Do not overclaim: This is not evidence that the Recipe Bot is reliable, that the rubric is validated, or that an automated evaluator is ready.

4 · Reproduce the lab

Boss, this is the actual sequence used to build and check the pilot. Every command is secret-free and uses an absolute path or runs from the repository root.

1. Create the blank lab

mkdir -p projects/recipe-bot-review-agreement

Expected: an empty project folder for the rubric, fixed trace list, and labels.

2. Create the three evidence files

touch rubric.md shared-set.md reviewer-a.csv

Observed: the owner wrote a binary rubric, ten fixed trace IDs, and one CSV row per trace.

3. Read one source trace

jq -r 'select(.id == "SYN016") | "QUERY:\n\(.query)\n\nRESPONSE:\n\(.response)"' ../../references/recipe-chatbot/homeworks/hw2/reference_files/query_response.jsonl

Expected: the original user query followed by the Recipe Bot response. Replace SYN016 with another shared ID.

4. Record the review

SYN016,Pass,"Recipe lists salmon fillets and lemon."

Observed: one concise, evidence-based Pass/Fail decision for every fixed trace.

Important: The first rubric attempted a dietary-restriction criterion. We stopped before treating it as evidence because the owner did not know the FODMAP domain well enough to judge it. The requested-ingredient rubric was the deliberate, understandable replacement.

5 · Run the validator

From the repository root, this command checks that the ten labels match the fixed ten IDs and reports the label distribution.

Command

uv run python projects/recipe-bot-review-agreement/check.py

Observed output: 250 source traces; 10 shared traces; 10 Reviewer A labels; 10 Pass; 0 Fail; no IAA / Cohen’s Kappa calculation.

Limitation: The validator confirms the pilot records are internally consistent. It cannot prove the rubric is valid or that two people would agree.

6 · Next

  • Build a new shared set with clear Pass cases, clear Fail cases, and borderline cases.
  • Ask a second human reviewer to label that set without seeing Reviewer A’s labels.
  • Measure agreement per criterion only after both independent label files exist.
Takeaway: A rubric must be clear, but agreement evidence also depends on independent reviewers and a test set that actually exercises the hard boundary.
