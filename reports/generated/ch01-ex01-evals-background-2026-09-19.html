Why AI Evals Exist

Boss, this is the simple picture: a defined case, a real AI response, a check, a fix, and a visible return arrow to test that fix.

1 · Think “new employee,” not “magic brain”

An AI can sound confident while guessing. An eval is a job check: did it do a particular task well enough in a particular situation?

A calculator

2 + 2 has one correct answer. Normal software tests can check it exactly.

Expected: 4. Any other result fails.

An AI support worker

“Where is my jollof order?” can have many well-written replies. Only some use the real order record and avoid inventing a delivery promise.

We need criteria, not only one expected sentence.

Short definition: an eval is evidence that an AI did a defined job well enough on a defined case.

2 · The evaluation loop, laid out straight

We use a straight line for the steps, then one visible right-angle arrow to show the return. After an improvement, you rerun the same cases before trusting it.

That is the point of evals: turn “that answer feels wrong” into a clear observation, a small fix, and a repeatable check.

3 · The Three Gulfs

The authors use “gulfs” for the three gaps between what we want and what an AI can reliably do.

GULF 1 · ANALYZE
Comprehension

“What is the AI actually doing?” Read the trace and find the first failure.

GULF 2 · MEASURE
Specification

“Have we clearly said what good means?” Turn vague wishes into prompts, rules, and pass/fail criteria.

GULF 3 · IMPROVE
Generalization

“Can it follow clear rules in new situations?” Test messy wording and edge cases.

Key rule: fix unclear instructions before blaming the model. Then test whether it can generalize when the task is truly clear.

4 · Three ways to check an AI

LevelSchool analogyAI example
L1 · CodeMarking arithmetic.Does the email summary contain a sender field? Is a phone number valid?
L2 · Quality reviewMarking an essay with a rubric.Was the refund answer accurate, helpful, and cautious?
L3 · ExperimentComparing two teaching methods.Does prompt B reduce customer escalations versus prompt A?
One level cannot do every job: a perfect format check cannot prove that an answer is useful or safe.

5 · Why the email summarizer is our first code lab

One small LLM call contains the whole idea.

Input

An email: “My account is locked. Reset it and call me.”

Task

Extract the sender and the key requests in a short summary.

Eval

Did it capture the request? Avoid quoted text? Handle the callback number? Invent nothing?

Learn

When it fails, inspect why: unclear prompt, missing data, or poor generalization?

Takeaway: Evals are not a final exam for AI. They are the feedback system that lets us see failure, make one improvement, and prove whether it helped.
