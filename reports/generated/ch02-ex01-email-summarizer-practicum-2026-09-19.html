The Email Summarizer: Build It Yourself

Boss, you will create a blank lab, write one real model call, print its answer, and keep that answer as your honest baseline.

22 September 2026 · Course Lesson 2 · Your self-built lab

1 · What you are doing — and not doing — today

Start in a blank folder you create yourself. One email goes in, one model answer comes out. No retrieval, tools, agents, grading, or prompt “improvement” yet.

1. Write one emailMake up a simple reset request in your own words.
2. Call the modelSend the prompt and your email to OpenAI once.
3. Print the answerSee exactly what the model said in the terminal.
4. Freeze the baselineDo not “fix” it before we inspect it together.
Why only one? Think of a keke rider testing the engine in an empty compound before carrying passengers. First, you learn what the machine actually does. Only then do you measure whether it is good enough.

2 · Model choice and a small billing truth

Use gpt-5-nano

For this narrow summarization task, it is the right starting point: OpenAI describes it as its fastest, cheapest GPT-5 model and specifically calls out summarization.

Current listed price: $0.05 / 1M input tokens and $0.40 / 1M output tokens.

API, not the ChatGPT app

A ChatGPT Plus, Pro, Business, or free account does not automatically pay for API requests. The practice script needs an API key and API-platform billing or credits.

We will never paste the key into a Python file or commit it to Git.

Tiny cost estimate: if this first request used roughly 400 input tokens and 100 output tokens, it would be about $0.00006 — far below one US cent. Actual cost depends on the final prompt and response length.

Why not the absolute cheapest possible model from somewhere else? We are following the book’s OpenAI/LiteLLM-style example and want one dependable provider while learning. Later, comparative evaluation can test a cheaper or different model on the same frozen cases.

5 · Create run_live.py

In your new projects/first-litellm-call folder, create a file called run_live.py. Type this first version yourself. Then change the email text so it is your own example. It prints the model’s raw answer.

import os

from litellm import completion

if not os.environ.get("OPENAI_API_KEY"):
    raise SystemExit("OPENAI_API_KEY is not set in this terminal.")

email = """Hello support team,
My account is locked after I changed phones.
Please reset my access and tell me when I can sign in again.
Thanks, Ada"""

response = completion(
    model="gpt-5",
    messages=[
        {
            "role": "system",
            "content": "Summarize the email in two short bullet points. Name the sender.",
        },
        {"role": "user", "content": email},
    ],
)

print(response.choices[0].message.content)
What “print out the first” means: the final two print() lines deliberately show you the untouched model response in the terminal. You are not asking it to pass a test yet. You are collecting the first trace.

6 · What success looks like today

After you run uv run python run_live.py, expect a terminal block shaped like this. Your actual wording may differ, and that is useful evidence.

- Ada needs her account access reset.
- She wants to know when she can sign in again.

If it prints an answer

Stop. Save or copy the whole output, including the model name. That is our baseline trace. Do not tune the prompt yet.

If it errors

Copy the error text, not your key. The likely early causes are: no API billing/credits, missing key in this terminal, or LiteLLM not installed in this project.

Important: a beautiful-looking answer is not a passing grade. In the next practicum we will run the five fixed emails, keep the outputs, and make the existing checker evaluate real model output instead of canned demonstrations.
