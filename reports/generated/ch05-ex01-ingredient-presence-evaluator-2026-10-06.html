Ingredient-Presence Evaluator

A small code check tests whether explicitly requested recipe ingredients appear in the response.

6 OCTOBER 2026 · SOURCE: CHAPTER 5 · ARTIFACT: RECIPE-BOT-AUTOMATED-EVALUATOR

1 · The question and metric

Boss, can a code-based evaluator catch a recipe that leaves out an ingredient the user explicitly requested?

Pass

Every ingredient in the case’s recorded requested-ingredient list appears in the recipe response.

Fail

At least one recorded requested ingredient is missing from the response.

In plain terms: It is like checking a market shopping list against the items in the bag. This check asks whether each listed item is there; it does not judge freshness, price, or quantity.

2 · What the code checks

The evaluator gets a canonical ingredient list for each case, then checks the recipe text with case-insensitive substring matching.

3 · Reproduce the lab

Run this from the repository root. The program reads the fixed case file and looks up real responses by ID in the source dataset.

Command and observed output

uv run python projects/recipe-bot-automated-evaluator/check.py

Observed: SYN025 and SYN031 matched Pass; fixture-001 matched Fail and reported salmon missing; 3/3 labels matched.

Limitation: Two real Pass examples and one synthetic Fail fixture demonstrate these three paths only. They do not estimate the Recipe Bot’s real failure rate or validate the rubric. Chapter 4’s decision still stands: wait for a second reviewer and a balanced clear-Pass/clear-Fail/borderline set before using this rubric operationally.

4 · Takeaway and next

  • Collect more reviewed cases, including real Fail examples and wording variations.
  • Check false matches caused by substrings and decide whether to add exact token boundaries or a reviewed alias map.
  • At the next session, explain why this objective check suits code and name one way it can still be wrong.
Takeaway: Code is fast and consistent for a narrow rule, but the evaluator only checks the structured ingredient names and text matches that we gave it.
