Ingredient Matching Edge Cases

We added one explicit ingredient alias and whole-word matching to handle two known errors in a deterministic checker.

7 OCTOBER 2026 · SOURCE: CHAPTER 5 · ARTIFACT: RECIPE-BOT-AUTOMATED-EVALUATOR

1 · The question

Boss, can a simple ingredient check accept one known synonym while avoiding a false match inside a longer word?

Alias false negative

The request says “scallions,” but the recipe says “green onions.” An exact-string check misses the ingredient even though the terms are treated as equivalent in this case.

Substring false positive

The request says “ham,” and the response says “shamrock.” A substring check finds the letters “ham” inside “shamrock” even though the ingredient is absent.

In plain terms: The alias map is a reviewed list of accepted names. Word boundaries make sure a name matches as a word or phrase, not as letters hidden inside another word.

2 · The evaluator and cases

Each case supplies a requested-ingredient list. For each ingredient, the code checks its explicit aliases with a regular-expression word boundary.

3 · Reproduce the lab

Run from the repository root. The script loads two real Recipe Bot traces and three synthetic fixtures from the case file.

Command and observed output

uv run python projects/recipe-bot-automated-evaluator/check.py

Observed: all five expected labels matched. The alias fixture passed; the ham/shamrock collision was marked Fail with ham missing.

Limitation: This five-case set tests hand-picked behavior. The two real cases are both Pass, and all three edge cases are synthetic. It does not estimate real failure rates, cover unlisted aliases, or establish human agreement.

4 · Takeaway and next

  • Find and manually review real Fail and borderline traces for requested-ingredient presence.
  • Keep synthetic edge cases separate from evidence about actual Recipe Bot behavior.
Takeaway: The alias and whole-word rules fix the two constructed examples; real, balanced reviewed cases are still needed to judge the evaluator on the bot.
